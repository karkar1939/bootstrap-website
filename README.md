# NomadSoft Solutions — Bootstrap 5 Website

This project is a responsive single-page website for a fictional custom software company. It uses Bootstrap 5 from the CDN and includes the required Home, Services, Case Studies, About, and Contact sections. The design includes a responsive navbar, three service cards, three project cards with accessible Bootstrap modals, company statistics, a testimonials carousel, and a contact form with client-side Bootstrap validation and simulated success feedback.

## Run it

Open `index.html` in a modern browser while connected to the internet. Bootstrap CSS/JavaScript, Bootstrap Icons, and Google Fonts are loaded from CDNs. The form is a front-end demonstration only: it does not send information to a server. The case studies, testimonials, and company statistics are illustrative sample content and should be replaced with real information if used commercially.

## Files

- `index.html` — page structure and Bootstrap components
- `assets/styles.css` — custom visual styling and responsive rules
- `assets/script.js` — modal content, form validation, navbar behavior, and current year
- `assets/favicon.svg` — simple vector favicon
